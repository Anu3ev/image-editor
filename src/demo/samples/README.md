# Demo assets

- `makers-table.png` is an original, deterministic raster illustration created for this repository. It is covered by the repository's MIT license. It depicts a fictional craft table, with no third-party images or trademarks.
- `sample-sans.woff` is a Latin, Cyrillic, and punctuation subset of DejaVu Sans, compressed as WOFF from the DejaVu font distribution. The license and notices are preserved in `FONT-LICENSE.txt`. It is loaded from this directory so sample text does not depend on installed fonts or external services.

All sample asset URLs are relative to the demo document and work under a nested project URL.
